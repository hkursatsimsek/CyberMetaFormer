# Topology OOD (rewired user → enterprise links)

Models trained on the MiniCAGE topology (user1/2 → ent0, user3/4 → ent1); evaluated on a rewired simulator (user1 → ent1, user2 → ent1, user3 → ent0, user4 → ent0; subnets, host count and observation layout unchanged, so the models run unmodified). B-line reads its enterprise target from the link table. The topology bias of CyberMetaFormer and the host-token GRU with topology bias is therefore misspecified; the other two host-token models have no topology bias. "Topology bias updated" rebuilds the relation matrix of the two topology-biased models from the rewired link table (same weights, no retraining). P2 applies the equivalent host permutation to the original episodes (decoy capacity moves with the host); P2s keeps the decoy-count columns in their slot, as in the rewired simulator, where decoy capacity stays with the host slot. Original, P2 and P2s share episodes (paired bootstrap); the rewired simulator has its own episodes (two-sample bootstrap, sets resampled independently). Mean ± sd over 5 seeds (argmax). 100,000 resamples; Holm over all 252 rows.
